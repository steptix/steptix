# The sample page

`pages/sample-page.html` is a small page that comes with the Steptix sample
project. It has one text box labelled **Name**, a **Save** button, and a
message below them: after Save it says "Saved for" and the name typed in, or
"Type a name first" when the box is empty.

Describe your own application here when you write tests for it: what it is
for, how people sign in, and the words it uses for things. Steptix gives this
file to the AI with every test in the project.
