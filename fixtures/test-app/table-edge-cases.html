Hidden rows and hidden columns

One row and one whole column are display: none. The read skips the hidden row — it is not data on this page, and it takes no _row number, so the three visible payments are rows 1 to 3 — while the hidden Reference column keeps its place in every row and reads as an empty string.

Icon-only cells and controls

Status is a ✓ or ✗ drawn by CSS, so the cell holds no text at all, and Auto-pay is a checkbox. Both read as an empty string today; reading the tick state is phase 2, through an explicit per-column mode — the Auto-pay checkbox as autopay reading "true" or "false" — which phase 1 refuses by name rather than quietly storing "".

Numbers as a bank writes them

Thousands separators, a leading plus, brackets for a negative, and a debit written with the Unicode minus U+2212 (−), which is a different character from the ASCII hyphen and which Number() rejects. The column reads normally as the exact text on the page; the whole-table checks that add a column up or prove it is sorted normalise these forms in phase 2.

A grid that is not a table

Same headings, same alignment, same borders — and not one <table> element in it. This is a <div role="grid"> with ARIA rows and cells, the shape ag-grid and MUI DataGrid produce. The read is deferred: it refuses anything that is not a native table rather than matching on the roles.

Card Number Limit Status

Savings Visa •••• 9082 $1,500.00 Blocked

Responsive table

Under 640px this table stops looking like a table: the headings are hidden and every row becomes a stacked card whose labels come from each cell's data-label. It still reads normally at any width, because the rows are still <tr> elements and only the CSS changed. Preview narrow squeezes this card to 400px so you can see the card layout without resizing the window.

Two named tables, not one grid

A table of headings with an empty body, and immediately after it — same parent, nothing in between — a table of three rows with no headings. That is the outline of a split grid (see split-grids.html), and it is not one: each table names itself, Pending orders and Order summary, so they are two things the page is showing, not two halves of one. A read of Pending orders reads normally and returns []; it must not borrow the rows from its neighbour.

Two unnamed tables with a heading between

The same two tables with neither an aria-label nor a <caption>, so nothing names either one — but an <h3>Summary</h3> sits between them. A heading between two tables is the page telling the reader that a new thing starts here, so these are still two tables and not a header half and a body half of one grid. A read of #t-unnamed-header reads normally and returns [].
