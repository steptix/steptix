# Issues

This folder tracks open design decisions, known limitations, and deferred
work that we want to revisit later. Each file is a single issue or decision.

Use it for things that are *decided for now but should be reconsidered* —
pragmatic trade-offs, heuristics we accepted, and areas where we deliberately
chose a simpler approach over a more correct one.

## Conventions

- One markdown file per issue, named `NNN-short-slug.md` (zero-padded number).
- Start with a short summary, then the context, decision, and revisit
  conditions.
- When an issue is resolved, move the file to `issues/resolved/` and add a
  closing note with the resolution date and outcome.
