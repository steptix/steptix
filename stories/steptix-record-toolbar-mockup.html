    Kept out of the recording

    • Its clicks and keys never reach the recorder or the app. Every recorder listener checks for the toolbar first, and its key handler runs before the page's.
    • Screenshot crops have it painted out, the way secret fields are, so it never blinks and the model never names it.
    • Page CSS, z-index and a strict CSP can't touch it. It lives in a closed shadow root in the browser's top layer, styled by an adopted stylesheet, in the system font because it can load nothing.
